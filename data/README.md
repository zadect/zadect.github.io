Data folder

Place raw source datasets (CSV/JSON) here. Each dataset should include a small metadata JSON file with fields:
- title
- description
- source
- url
- license
- last_updated

Initial datasets to add later:
- world-hunger.csv (+ world-hunger.meta.json)
- ceo-vs-average.csv (+ ceo-vs-average.meta.json)

Guidelines:
- Prefer Our World in Data, World Bank, OECD, or primary research sources.
- Keep original raw files; include any processing scripts in scripts/ with reproducible steps.
